# 拼豆像素编辑器设计规格

## 目标

构建一个可托管到 GitHub Pages 的静态 Web 工具，用于把用户图片处理成可制作、可精修、可保存、可导出的拼豆工程。产品定位是“拼豆专用像素画编辑器”：进阶玩家优先，但保留新手可走通的生成助手。

第一版重点：

- 图片导入、裁剪、背景降噪、主体分离。
- 主题像素化，并映射到国内玩家常用拼豆色卡。
- 像素级精修、换色、禁用色、库存约束。
- 单文件 `.pindou` 工程保存、本机打开、WebDAV 同步。
- 导出 PDF/PNG 图纸和网页内交互式制作步骤。
- 桌面和手机均支持完整编辑。

## 领域理解

拼豆制作的实际流程是：选图或设计图案，确定豆径和拼板尺寸，生成或绘制像素图，按真实色卡选豆，逐格摆放，使用烫纸隔离后熨烫，冷却定型，必要时翻面补烫或装裱。

工具必须解决的是前期准备返工问题：

- 原图背景太乱，影响主体边缘。
- 普通像素化会产生脏色、碎点和不可购买的颜色。
- 真实拼豆依赖厂商色号和库存，而不是任意 RGB。
- 大图需要按拼板拆分，并提供坐标、色号和制作顺序。
- 用户经常需要二次编辑，而不是一次性导出图片。

## 参考项目

- Zippland/perler-beads：参考其拼豆专用思路，包括主导色像素化、边界背景移除、颜色排除/重映射、手动精修、图纸和材料清单。只作为产品和算法参考，不复制 AGPL-3.0 代码。
- Perler/Hama 官方说明：参考真实拼豆制作流程、拼板、烫纸和熨烫步骤。
- 同类在线工具：参考上传图片、选择尺寸、映射色卡、导出图纸的基础闭环。

## 产品结构

第一版采用“像素画编辑器优先”的结构，而不是流程向导。

桌面主界面：

- 顶部工具栏：项目名、导入、保存、WebDAV 状态、撤销、重做、缩放、视图模式、导出。
- 左侧面板：项目资源、图层、历史快照、生成助手入口。
- 中央画布：原图、像素图、色号蓝图、分板、制作步骤等视图。
- 右侧面板：工具参数、色卡品牌、当前颜色、禁用色、库存、替换色、材料清单。
- 底部状态栏：尺寸、豆径、总豆数、选中色、分板页、保存状态。

新手路径通过“生成助手”提供：导入图片后可按裁剪、背景、像素化、色卡、导出顺序走完。

## 图片处理流程

处理链路必须可回退，每个阶段写入工程。

1. 导入与标准化
   - 支持 JPG、PNG、WebP。
   - 修正 EXIF 方向。
   - 保存原图副本和预览缩略图。
   - 大图在浏览器本地降采样，保护手机性能。

2. 裁剪与尺寸
   - 支持自由裁剪、固定比例裁剪、旋转和缩放。
   - 支持按格数、厘米尺寸、豆径、拼板数量互相反推。

3. 背景降噪与主体分离
   - 默认本地处理：边界洪水填充、相近色阈值、手动擦除和恢复 mask。
   - 可选外部 API：用户配置 key 后启用 AI 抠图或降噪。
   - 外部 API 输出仍保存为本地 mask，可继续手修。

4. 像素化
   - 支持最近邻、区域主导色、边缘保留三种模式。
   - 默认使用区域主导色，减少平均色导致的脏边。
   - 支持色块合并、孤立点清理、最小连通区域。

5. 色卡映射
   - 第一版优先覆盖国内玩家常用色卡：MARD、COCO、漫漫、盼盼、咪小窝。
   - 每个颜色包含品牌、色号、中文名、RGB 近似值、规格、库存状态。
   - 映射使用感知色差。
   - 支持禁用色、缺货色、锁定品牌、混合多品牌、手动替换。

6. 精修编辑
   - 提供画笔、橡皮、吸管、油漆桶、选择、替换色、局部重新映射。
   - 支持撤销和重做。
   - 手动改动存在编辑层，不破坏原始生成结果。

7. 输出准备
   - 自动生成材料清单、每色数量、分板坐标、色号图例、制作顺序。
   - 支持按颜色、按区域、按板块生成步骤。

## 工程文件

工程文件采用单文件 `.pindou`。内部使用 ZIP 容器，用户看到的是一个文件，但里面结构化存放 JSON、图片、mask 和导出缓存。

建议结构：

```text
manifest.json
source/original.webp
source/crop.json
masks/subject.png
grid/base.json
grid/edits.json
palettes/*.json
inventory.json
exports/settings.json
preview.webp
```

字段职责：

- `manifest.json`：工程版本、创建时间、应用版本、项目名、画布宽高、豆径、拼板规格。
- `source/original.webp`：导入原图的标准化副本。
- `source/crop.json`：裁剪框、旋转、缩放、EXIF 修正信息。
- `masks/subject.png`：主体 mask。
- `grid/base.json`：基础像素网格，每格记录颜色 ID 和空格状态。
- `grid/edits.json`：编辑日志或压缩覆盖层。
- `palettes/*.json`：本项目使用的品牌色卡快照，防止旧项目随色卡更新变色。
- `inventory.json`：库存、禁用色、缺货色、替代策略。
- `exports/settings.json`：PDF、PNG、制作步骤、图例样式、分页设置。
- `preview.webp`：项目封面缩略图。

## 存储

本机保存：

- 默认导入和导出 `.pindou`。
- 支持 File System Access API 时提供直接保存和另存为。
- 不支持时退化为下载文件。

自动恢复：

- IndexedDB 保存最近工程和自动恢复点。
- IndexedDB 不作为唯一存储，必须提醒用户保存 `.pindou`。

WebDAV：

- 用户配置 URL、用户名、密码或 token 后启用。
- 同步单个 `.pindou` 文件。
- 记录远端 ETag 和 Last-Modified。
- 发生冲突时保留本地副本和远端副本，不静默覆盖。

隐私：

- 默认所有图片和工程只在浏览器本地处理。
- 外部 API 和 WebDAV 必须由用户主动配置。

## 导出

第一版同时支持离线图纸和交互式制作步骤。

PDF/PNG 图纸：

- 按拼板分页。
- 显示网格、坐标、色号或符号。
- 附色号图例和材料清单。
- 支持彩色版、黑白符号版、空格透明版。

网页内制作步骤：

- 从工程中进入制作模式。
- 支持按颜色、按区域、按拼板逐步高亮。
- 支持当前步骤、下一步、已完成标记。
- 手机端优先优化该模式，但仍保留完整编辑能力。

## UI 设计

整体气质是专业编辑器，而不是营销页。界面应安静、密集、清晰，画布和色卡是视觉核心。

桌面：

- 顶部是紧凑工具栏，图标为主，关键命令保留文字。
- 左侧是图层和项目面板。
- 中央是大画布，支持网格、坐标、拼板边界、透明棋盘格、色号叠加。
- 右侧是检查器和色卡面板。
- 底部是状态栏。

手机：

- 画布全屏优先。
- 顶部保留项目栏和保存状态。
- 底部工具坞放画笔、橡皮、吸管、填充、选择、颜色。
- 图层、色卡、参数、导出使用底部抽屉。
- 支持双指缩放、单指拖动画布、长按取色、局部放大镜。

视觉约束：

- 避免单一深蓝、紫色或奶油色主题。
- 使用中性浅灰和石墨黑混合界面。
- 强调色来自拼豆多色和少量青绿色、琥珀色状态色。
- 圆角不超过 8px。
- 色卡以小色块、色号、库存状态呈现，不使用大卡片堆叠。
- 图标优先使用 lucide 风格。

## 技术约束

- 静态部署，适合 GitHub Pages。
- 不依赖服务端即可完成核心流程。
- 图片处理、工程保存、导出尽量使用浏览器本地能力。
- 外部 API 只作为可选增强。
- 许可证上不复制 AGPL 项目代码，只参考公开产品形态和算法思路。

## 成功标准

- 用户可以从图片生成真实可摆豆的网格。
- 用户可以用国内常用色卡和库存约束修正颜色。
- 用户可以保存 `.pindou` 并重新打开继续编辑。
- 用户可以同步到 WebDAV。
- 用户可以导出 PDF/PNG 图纸和交互式制作步骤。
- 手机端可以完整完成导入、编辑、保存和导出。
